# Portfolio typography

These locally served font subsets are shared with PortfolioV2:

- Bricolage Grotesque (normal, Latin and Latin extended)
- Newsreader (italic, Latin and Latin extended)

Both families are distributed under the SIL Open Font License. Fonts are loaded
from this site rather than from Google Fonts. The extended subsets support
additional European characters alongside the Latin subsets, including Norwegian.
